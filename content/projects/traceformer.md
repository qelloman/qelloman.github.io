# TraceFormer

S-parameter Prediction Framework for PCB Traces based on Graph Transformer.

## Overview
Predicting S-parameters of SSD PCB traces using graph representations and transformer architecture.

## Highlights
- Developed a PCB data generator with product-level design rules and constraints
- Built S-parameter (2401 x 2 x 210 dimension) prediction model
- Utilized geometrical and topological features from graph representations
- Achieved R2>0.85 up to 15GHz

## Publication
Published at **ACM/IEEE Design Automation Conference (DAC) 2024**

## Tech
`Python` `PyTorch` `Graph Transformer`
