# Rust를 배우며

*2024.10.05*

Rust는 어렵다. 하지만 그만큼 가르쳐주는 것이 많다.

## Borrow Checker와의 싸움
처음엔 컴파일러가 적이었다.
"왜 이걸 못하게 하는 거지?"

지금은 안다.
컴파일러는 적이 아니라 **가장 엄격한 코드 리뷰어**다.

## Rust가 바꾼 내 사고방식
- 소유권을 의식하게 됨
- 에러 처리를 "나중에"가 아닌 "지금" 하게 됨
- "이거 메모리 안전한가?" 를 항상 생각
- 타입 시스템으로 불가능한 상태를 표현
